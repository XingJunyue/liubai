# 留白

一款真正限制使用时长的安卓自律 APP。

- 自定义受限应用与每日时长，用完锁到第二天 0:00
- 当天只能改得更严：调高时长、移除应用、停用守护都要到次日 0:00 才生效
- 用完后打开受限应用会被送回桌面并显示温馨提示，没有「延长」按钮
- 防反悔内置：守护期间在系统设置里关闭留白相关项会被拦回
- 两个桌面小部件：2×2 剩余时间圆环、4×2 今日进度列表

## 安装后设置（小米 / HyperOS）

1. 设置 → 应用 → 留白 → 右上角「允许受限制的设置」
2. 无障碍 → 已下载的应用 → 留白 → 开启
3. 授予「使用情况访问权限」
4. 自启动开启、省电策略设为「无限制」、允许「后台弹出界面」

## 构建

推送后 GitHub Actions 自动构建，产物为 `liubai.apk`（Actions → 最新 run → Artifacts）。
